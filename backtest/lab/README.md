# مختبر الاستراتيجيات (vectorbt)

محرك موحّد لاختبار أي استراتيجية على أسهم S&P 500 (حوالي 500 سهم، 10 سنوات، فاصل يومي)
قبل بناء ماسح لها.

## التشغيل من الجوال
GitHub ← Actions ← **Strategy Lab (vectorbt)** ← Run workflow ← اختر الاستراتيجية.
النتيجة تُحفظ في `backtest/lab/results/<الاستراتيجية>.md`.

## كيف تُقرأ النتيجة
- **excess**: عائد الصفقة ناقص متوسط عائد كل الأسهم في نفس يوم الدخول.
  هذا هو السؤال الحقيقي: هل الإشارة أفضل من شراء أي سهم ذلك اليوم؟
- **t_stat**: قوة التفوق. أقل من 2 = لا يختلف عن الصدفة. الموثوق: 3 فأكثر.
- **excess_1st_half / 2nd_half** و **good_years**: هل التفوق ثابت عبر الزمن أم جاء من فترة واحدة.
- **pf_\***: صفقات فعلية بالوقف والهدف والحد الزمني ورسوم 0.1% لكل جهة.

## إضافة استراتيجية جديدة
في `strategies.py`: اكتب دالة ترجع `{"long": DataFrame منطقي}` (واختيارياً `short`, `sl`, `tp`)
ثم أضفها إلى `STRATEGIES` مع إعداداتها الافتراضية وشبكة التجربة. وأضف اسمها في قائمة
الخيارات في `.github/workflows/lab.yml`.
