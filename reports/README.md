# reports/

مخرجات "صائد الفرص" (`mispriced_hunter.py`) — الطبقة الآلية من معيار اختيار الشركات.

- `hunter_latest.json` — آخر دورة (يُستبدل شهرياً)
- `hunter_YYYY-MM.json` — أرشيف كل دورة

يحتوي كل ملف على القائمة القصيرة مع درجات الأسئلة ٣ و٤ و٦، وقائمة
المستبعدين ببوابة الإقصاء. الأسئلة ١ و٢ و٥ تبقى فارغة عمداً —
تُجاب في طبقة الحكم (المهمة المجدولة).
