# ماسح السوق السعودي (تداول)

ماسح مستقل عن ماسحات السوق الأمريكي في هذا الريبو.

- **الاستراتيجية:** اختراق المتوسط 100 بهدف المتوسط 200، فاصل يومي، فوليوم ≥ ضعف متوسط 20 يوماً، الوقف قاع شمعة الاختراق، وأدنى سيولة يومية مليون ريال.
- **البيانات:** Yahoo Finance (رموز `.SR`)، وقائمة الأسهم من TradingView مع قائمة احتياطية في `sa_universe.txt`.
- **التشغيل:** `.github/workflows/sa_scan.yml`، يُطلقه حدث `sa_ma` من مهمة مجدولة الأحد–الخميس 15:45 بتوقيت الرياض، أو يدوياً من Actions.
- **الواجهة:** `docs/sa/index.html` على GitHub Pages، وتقرأ ملفات `docs/sa/data/*.json` التي يحدّثها الماسح بعد كل فحص.
- **تيليجرام:** يستخدم `TG_TOKEN` و`TG_CHAT`، أو `SA_TG_TOKEN` و`SA_TG_CHAT` إذا أُضيفت لمحادثة منفصلة.

الإعدادات كلها في أعلى `sa_ma_scanner.py` (القاموس `SETTINGS`).
